 Project Overview

This project focuses on auditing and analyzing Git, a widely used distributed version control system.
The primary goal is to explore the principles, licensing model, and practical applications of open-source software.

In addition to theoretical concepts, this project also demonstrates hands-on implementation using a Linux environment and shell scripting.

 Why I Chose Git

While developing programs, I found it challenging to manage multiple versions of code manually.
Learning Git made it much easier to track modifications, collaborate, and maintain project history efficiently.

This motivated me to study Git in detail and select it for this audit project.

 Shell Scripts Included

This project contains five shell scripts:

Script 1: System Information Reporter
Displays details such as kernel version, current user, system uptime, and OS distribution.

Script 2: Git Package Checker
Verifies whether Git is installed on the system and displays its version.

Script 3: File System Auditor
Examines directories and shows file permissions, ownership, and sizes.

Script 4: Log Analyzer
Processes a log file and counts how many times a specific keyword appears.

Script 5: Open Source Statement Generator
Accepts user input and creates a customized text file.

How to Run the Scripts
Open terminal (Linux / WSL)

Navigate to the project directory:

cd oss-project

Grant execution permission:

chmod +x script1.sh

Execute the script:

./script1.sh

For Script 4:

./script4.sh log.txt

All script outputs are captured as screenshots and included in the project documentation.
